## 오늘의 개념: 벡터 데이터베이스란 무엇인가
우리가 도서관에서 책을 찾을 때 제목이나 저자 이름으로 검색하는 것처럼, 컴퓨터도 데이터를 저장하고 찾는 방법이 필요합니다. 그런데 AI는 글, 사진, 소리 같은 것들을 '숫자로 이루어진 좌표' 형태로 이해하는데, 이 좌표 뭉치를 '벡터'라고 부릅니다. 마치 지도 위에서 우리 집과 친구 집의 위치를 좌표로 나타내면 두 집이 얼마나 가까운지 알 수 있는 것처럼, 벡터로 표현된 데이터끼리도 얼마나 '의미가 비슷한지' 거리로 계산할 수 있습니다. 벡터 데이터베이스는 이런 벡터(좌표) 형태의 데이터를 잔뜩 저장해두고, "이 내용과 비슷한 것을 찾아줘"라고 물으면 가장 가까운 좌표에 있는 데이터를 빠르게 찾아주는 특별한 창고 같은 것입니다. 예를 들어 챗봇이 사용자의 질문과 의미가 비슷한 문서를 찾아서 답변할 때 이 벡터 데이터베이스를 활용합니다.

## 오늘의 용어: 벡터 데이터베이스 (Vector Database)
벡터 데이터베이스는 컴퓨터가 글, 사진, 소리 같은 데이터의 '의미'를 숫자로 바꿔서 저장해두는 특별한 창고예요. 예를 들어 도서관에서 책을 제목의 가나다순이 아니라 '내용이 비슷한 책끼리' 모아두면 원하는 주제의 책을 훨씬 빨리 찾을 수 있는 것처럼, 이 데이터베이스는 의미가 비슷한 정보들을 가까이 두어서 "이거랑 비슷한 걸 찾아줘"라는 질문에 빠르고 정확하게 답할 수 있게 해줍니다.</definition>

## 예제 코드
```python
import numpy as np  # 숫자 계산을 도와주는 도구를 가져옵니다 (벡터=숫자 목록을 다루기 위함)

# 문장들을 미리 숫자 목록(벡터)으로 바꿔서 저장해둡니다 (실제로는 AI 모델이 이 변환을 해줍니다)
database = {
    "고양이가 자고 있다": np.array([0.9, 0.1, 0.0]),
    "강아지가 뛰어논다":   np.array([0.1, 0.9, 0.0]),
    "오늘 날씨가 좋다":    np.array([0.0, 0.0, 0.9]),
}

# 새로 검색하고 싶은 문장을 벡터로 표현합니다 (고양이와 비슷한 느낌으로 설정)
query = np.array([0.8, 0.2, 0.0])

# 벡터끼리 얼마나 비슷한지 계산하는 함수 (값이 클수록 더 비슷함)
def similarity(a, b):
    return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))

# 저장된 모든 문장과 비교해서 가장 비슷한 문장을 찾습니다
best_sentence = None
best_score = -1
for sentence, vector in database.items():
    score = similarity(query, vector)  # 비슷한 정도 계산
    if score > best_score:            # 지금까지 중 가장 비슷하면
        best_score = score
        best_sentence = sentence      # 그 문장을 기억해둡니다

# 가장 비슷한 문장을 결과로 보여줍니다
print("가장 비슷한 문장:", best_sentence)

```
벡터 데이터베이스는 물건을 '의미가 비슷한 정도'로 정리해두는 창고와 비슷합니다. 예를 들어 도서관에서 책을 제목 순서가 아니라 '내용이 비슷한 책끼리' 가까운 칸에 꽂아두면, 원하는 주제의 책 옆에서 비슷한 책을 쉽게 찾을 수 있는 것과 같은 원리입니다. 이 코드는 문장들을 숫자 목록(벡터)으로 바꿔서 저장하고, 새로운 문장이 들어왔을 때 가장 '의미가 비슷한' 문장을 찾아주는 아주 단순한 벡터 데이터베이스 흉내를 냅니다.

## 실무 팁
벡터 데이터베이스란, 쉽게 말하면 '의미가 비슷한 것끼리 가까운 곳에 정리해 놓는 창고'입니다. 예를 들어 도서관에서 책을 제목 알파벳 순서가 아니라 '내용이 비슷한 책끼리' 모아 놓는다고 생각하면 됩니다. 컴퓨터는 글자나 이미지를 '숫자 목록(벡터)'으로 바꿔서 저장하는데, 이 숫자들이 비슷하면 의미도 비슷한 것으로 취급됩니다. 실제로 바로 체험해보고 싶다면, 무료로 쓸 수 있는 Chroma(파이썬 라이브러리, pip install chromadb)를 설치한 뒤, 아래처럼 3줄짜리 문장 5개를 넣고 "강아지에 관한 문장을 찾아줘"라고 검색해보세요. 코드는 이렇습니다: 
1) import chromadb; client = chromadb.Client()
2) collection = client.create_collection("test")
3) collection.add(documents=["나는 강아지를 좋아한다", "오늘 날씨가 좋다", "고양이는 귀엽다", "강아지와 산책했다", "커피를 마셨다"], ids=["1","2","3","4","5"])
4) collection.query(query_texts=["반려동물"], n_results=2)
이렇게 실행하면 "강아지"와 "고양이"가 들어간 문장이 상위로 검색되는 걸 눈으로 확인할 수 있어서, '벡터 검색이 의미로 검색한다'는 개념이 확 와닿습니다.

## 오늘의 퀴즈
Q. 우리가 물건을 찾을 때 도서관에서 책 제목을 정확히 알아야 찾을 수 있는 방법과, "이런 느낌의 이야기책 없나요?"라고 물어보면 사서가 비슷한 분위기의 책들을 골라주는 방법이 있어요. 벡터 데이터베이스는 이 두 가지 방법 중 어느 쪽에 더 가깝고, 왜 그런지 설명해보세요.
A. 벡터 데이터베이스는 "비슷한 느낌의 책을 찾아주는 사서" 방법에 더 가까워요. 왜냐하면 벡터 데이터베이스는 글자나 이미지 같은 정보를 컴퓨터가 이해할 수 있는 숫자 목록(벡터)으로 바꿔서 저장하는데, 이 숫자 목록은 그 정보의 '의미'나 '특징'을 담고 있기 때문이에요. 예를 들어 "강아지"와 "puppy"라는 단어는 철자는 완전히 다르지만 의미가 비슷하기 때문에 벡터로 바꾸면 숫자 목록이 서로 가깝게 만들어져요. 그래서 정확히 똑같은 단어를 몰라도, "이것과 비슷한 의미를 가진 것"을 빠르게 찾아낼 수 있는 것이 벡터 데이터베이스의 핵심이에요. 마치 사서가 책 제목은 몰라도 "따뜻한 감동 이야기"라는 느낌만으로 비슷한 책들을 척척 찾아주는 것처럼요.
