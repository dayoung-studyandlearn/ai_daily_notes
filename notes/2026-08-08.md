## 오늘의 개념: 하이브리드 검색이란 무엇인가
하이브리드 검색은 두 가지 서로 다른 검색 방법을 합쳐서 더 좋은 결과를 찾아내는 방법이에요. 첫 번째 방법은 '키워드 검색'인데, 이건 마치 책에서 특정 단어를 찾을 때 정확히 그 단어가 있는 페이지를 찾는 것과 같아요. 예를 들어 '사과'라고 검색하면 '사과'라는 글자가 들어간 문서만 찾아줍니다. 두 번째 방법은 '의미 기반 검색(벡터 검색)'인데, 이건 단어가 똑같지 않아도 뜻이 비슷한 것을 찾아주는 방법이에요. 마치 친구에게 "빨간 과일 좀 사다줘"라고 했을 때 친구가 '사과'라는 단어를 못 들었어도 눈치껏 사과를 사오는 것과 비슷해요. 하이브리드 검색은 이 두 가지를 동시에 사용해서, 정확한 단어도 놓치지 않고 비슷한 의미의 내용도 함께 찾아주기 때문에 검색 결과가 훨씬 풍부하고 정확해집니다.

## 오늘의 용어: 하이브리드 검색 (Hybrid Search)
하이브리드 검색은 두 가지 서로 다른 검색 방법을 함께 사용해서 더 정확한 검색 결과를 찾아주는 방법입니다. 하나는 '키워드 검색'으로, 마치 책에서 특정 단어가 정확히 들어간 페이지를 찾는 것처럼 사용자가 입력한 단어와 똑같은 단어가 있는 문서를 찾는 방식입니다. 다른 하나는 '의미 기반 검색'으로, 단어가 정확히 같지 않아도 뜻이 비슷한 내용을 찾아주는 방식인데, 예를 들어 "강아지"라고 검색해도 "반려견"이라는 단어가 있는 문서를 찾아주는 것과 비슷합니다. 하이브리드 검색은 이 두 가지를 마치 요리에 여러 재료를 섞어 더 맛있는 음식을 만드는 것처럼 함께 활용해서, 정확한 단어 매칭과 의미적 유사성을 모두 고려한 똑똑한 검색 결과를 제공합니다.

## 예제 코드
```python

# 검색 대상이 되는 문장들 (마치 책 제목 목록 같은 것)
documents = [
    "고양이는 낮잠을 좋아한다",
    "강아지는 산책을 좋아한다",
    "고양이와 강아지는 친구가 될 수 있다"
]

# 사용자가 입력한 검색어 (예: "고양이"라는 단어를 찾고 싶음)
query = "고양이"

# 의미 기반 검색을 흉내내기 위한 '미리 정해둔 유사도 점수'
# (실제로는 AI가 문장의 뜻을 이해해서 계산하지만, 여기서는 예시로 숫자를 넣음)
semantic_scores = [0.9, 0.2, 0.7]

# 키워드 검색: 문장에 검색어가 그대로 포함되어 있으면 1점, 없으면 0점
keyword_scores = [1 if query in doc else 0 for doc in documents]

# 하이브리드 검색: 키워드 점수와 의미 점수를 더해서 최종 점수 계산
hybrid_scores = [k + s for k, s in zip(keyword_scores, semantic_scores)]

# 최종 점수가 높은 순서대로 문장을 정렬해서 출력 (가장 관련 있는 문장이 먼저 나옴)
ranked = sorted(zip(documents, hybrid_scores), key=lambda x: x[1], reverse=True)

# 결과 확인: 문장과 최종 점수를 함께 보여줌
for doc, score in ranked:
    print(f"{doc} -> 점수: {score}")

```
하이브리드 검색이란, 도서관에서 책을 찾을 때 "제목에 특정 단어가 들어간 책"을 찾는 방법과 "내용이 비슷한 책"을 찾는 방법을 동시에 사용하는 것과 비슷합니다. 즉, 정확한 단어가 일치하는지 보는 방법(키워드 검색)과 의미가 비슷한지 보는 방법(의미 기반 검색)을 합쳐서 더 좋은 검색 결과를 찾는 방식입니다. 아래 코드는 아주 단순화된 방식으로, 문장 속에 검색어가 그대로 들어있으면 점수를 주고(키워드 검색), 동시에 미리 정해둔 '비슷한 의미의 점수'도 더해서(의미 기반 검색 흉내), 두 점수를 합쳐 최종 순위를 정하는 예제입니다.

## 실무 팁
'하이브리드 검색'은 쉽게 말해 도서관에서 책을 찾을 때 두 가지 방법을 동시에 쓰는 것과 같아요. 첫 번째 방법은 '키워드 검색'인데, 이건 마치 책 제목이나 목차에 있는 정확한 단어를 찾는 것처럼 내가 입력한 단어와 똑같은 단어가 들어있는 문서를 찾아줍니다(전문 용어로는 'BM25' 또는 '키워드 매칭'이라고 불러요). 두 번째 방법은 '의미 검색'인데, 이건 사서에게 "요즘 우울할 때 읽을 만한 책 있나요?"라고 물으면 '우울'이라는 단어가 없어도 위로가 되는 책을 추천해주는 것처럼, 단어가 정확히 일치하지 않아도 의미가 비슷한 문서를 찾아줍니다(이걸 컴퓨터가 하려면 문서를 숫자 목록(벡터)으로 바꿔서 비교하는데, 이를 '벡터 검색'이라고 해요). 하이브리드 검색은 이 두 가지를 합쳐서, 정확한 단어도 잡아내고 의미도 놓치지 않게 하는 방법입니다. 실무 팁: 만약 RAG(문서를 찾아서 AI에게 답을 만들게 하는 시스템)를 만들고 있다면, Elasticsearch나 Weaviate, Qdrant 같은 도구에서 제공하는 '하이브리드 검색' 기능을 켜보세요. 보통 설정에서 키워드 검색 점수와 벡터 검색 점수의 비율(예: 0.5:0.5)을 조절할 수 있는데, 처음에는 이 비율을 절반씩 시작한 다음, 실제 검색 결과를 보면서 '정확한 단어가 중요한 검색'인지 '의미가 중요한 검색'인지에 따라 비율을 7:3이나 3:7로 조금씩 바꿔가며 테스트해보는 것이 좋습니다.</tip>


## 오늘의 퀴즈
Q. 도서관에서 '사랑'이라는 단어가 정확히 들어간 책을 찾는 방법과, '사랑'이라는 단어는 없어도 사랑을 주제로 다루는 책(예: '연인', '이별' 같은 단어가 쓰인 책)까지 찾는 방법이 있다고 할 때, 하이브리드 검색은 이 두 가지 방법을 어떻게 활용하는 걸까요? 그리고 왜 두 가지를 같이 쓰는 게 하나만 쓰는 것보다 더 좋을까요?
A. 하이브리드 검색은 '정확한 단어 매칭 검색(키워드 검색)'과 '의미가 비슷한 것을 찾는 검색(의미 기반 검색)'을 동시에 사용하는 방법입니다. 예를 들어 키워드 검색은 정확히 '사랑'이라는 단어가 들어간 책만 찾아주고, 의미 기반 검색은 '사랑'이라는 단어가 없어도 '연인', '이별'처럼 의미상 관련된 책까지 찾아줍니다. 이 둘을 같이 쓰면, 정확한 단어를 놓치지 않으면서도 의미적으로 관련된 내용까지 폭넓게 찾을 수 있어서, 한 가지 방법만 쓸 때보다 훨씬 더 정확하고 풍부한 검색 결과를 얻을 수 있습니다.
