## 오늘의 개념: Self-Attention이 문맥을 이해하는 원리
우리가 "은행에 돈을 맡기러 갔다"라는 문장을 읽을 때, '은행'이라는 단어가 '금융기관'을 뜻하는지 '강가'를 뜻하는지는 주변 단어인 '돈'을 보고 자연스럽게 판단합니다. Self-Attention은 컴퓨터가 문장을 이해할 때 바로 이런 과정을 흉내 내는 방법입니다. 문장 속의 각 단어가 다른 모든 단어들을 한 번씩 둘러보면서 "너는 나랑 얼마나 관련이 있니?"라고 점수를 매기고, 관련이 깊은 단어에는 더 집중(가중치를 높게)하고 관련이 적은 단어는 덜 신경 쓰는 방식입니다. 마치 시끌벅적한 파티에서 여러 사람이 동시에 말해도, 내가 대화 중인 상대방 목소리에는 집중하고 나머지 소음은 흘려듣는 것과 비슷합니다. 이렇게 모든 단어가 서로를 참고하며 관계를 파악하기 때문에, AI는 같은 단어라도 문맥에 따라 다른 의미로 이해할 수 있게 됩니다. 이 기술이 바로 ChatGPT 같은 최신 AI 모델들의 핵심 기반이 되는 원리입니다.

## 오늘의 용어: Self-Attention (셀프 어텐션)
Self-Attention은 AI가 문장 속 단어들을 읽을 때, 각 단어가 다른 모든 단어들과 얼마나 관련이 있는지를 서로 비교해보고 중요한 단어에 더 집중하는 방법이에요. 예를 들어 "강아지가 공을 물었는데, 그것은 매우 튼튼했다"라는 문장에서 '그것'이 '공'을 가리키는지 '강아지'를 가리키는지 알아내려면, AI는 '그것'이라는 단어가 문장 속 다른 단어들과 얼마나 연관되어 있는지를 하나하나 점수 매겨서 판단합니다. 마치 여러 사람이 모여 회의할 때 발언자가 이야기할 내용과 관련해서 누구의 말을 더 귀담아들어야 할지 자연스럽게 판단하는 것과 비슷한 원리라고 생각하면 됩니다.</definition>

## 예제 코드
```python
import numpy as np  # 숫자 계산(특히 벡터, 행렬 계산)을 쉽게 해주는 도구를 가져옵니다.

# 각 단어를 숫자로 표현한 것입니다. (실제로는 훨씬 복잡하지만 여기선 간단히 3개 숫자로 표현)
# "나는", "사과를", "그것은" 이라는 3개 단어가 있다고 가정합니다.
word_vectors = np.array([
    [1, 0, 1],  # "나는" 을 표현한 숫자들
    [0, 1, 1],  # "사과를" 을 표현한 숫자들
    [1, 1, 0],  # "그것은" 을 표현한 숫자들
])

# 단어들끼리 서로 얼마나 비슷한지(관련 있는지) 점수를 계산합니다.
# 벡터끼리 곱해서 더하면(내적), 방향이 비슷할수록 큰 숫자가 나옵니다.
# 즉, 이 점수가 클수록 두 단어가 더 "관련 있다"는 뜻입니다.
similarity_scores = np.dot(word_vectors, word_vectors.T)

print("단어들 간의 관련도 점수표:")
print(similarity_scores)

# 점수를 0~1 사이의 "집중 비율"로 바꿔줍니다. (전체 합이 1이 되도록 정리)
# 이렇게 하면 "이 단어가 다른 단어들 중 어디에 몇 %만큼 집중하는지" 알 수 있습니다.
def softmax(x):
    e_x = np.exp(x - np.max(x))  # 너무 큰 숫자가 나오지 않도록 안전하게 조정
    return e_x / e_x.sum(axis=1, keepdims=True)  # 각 줄(행)의 합이 1이 되도록 나눔

attention_weights = softmax(similarity_scores)

print("\n각 단어가 다른 단어들에 얼마나 집중하는지 비율(Self-Attention 가중치):")
print(attention_weights)

# 결과 해석: "그것은"(3번째 줄)이 "나는"과 "사과를" 중 어디에 더 집중하는지 보면
# 문맥을 이해하는 과정을 아주 단순하게 흉내낼 수 있습니다.

```
Self-Attention이란 문장 속 단어들이 서로 얼마나 관련 있는지를 계산해서, 각 단어가 문맥을 파악하도록 돕는 방법입니다. 예를 들어 "나는 사과를 먹었다. 그것은 맛있었다."라는 문장에서 "그것"이 "사과"를 가리킨다는 것을 알아채려면, "그것"이라는 단어가 문장 속 다른 단어들과 얼마나 관련(유사도)이 있는지 점수를 매겨야 합니다. 이 코드는 아주 단순화된 방식으로, 단어 간의 유사도 점수를 계산하고, 그 점수를 바탕으로 어떤 단어에 더 집중(주의, attention)해야 하는지를 숫자로 보여줍니다. 마치 여러 사람이 회의를 할 때, 누가 누구의 말을 얼마나 귀담아듣는지 '집중도 점수'를 매기는 것과 비슷합니다.

## 실무 팁
Self-Attention은 "문장 속 각 단어가 다른 모든 단어를 한 번씩 쳐다보면서 '너랑 나랑 얼마나 관련 있어?'라고 점수를 매기는 과정"이라고 이해하면 쉽습니다. 예를 들어 "나는 사과를 먹었는데, 그것은 매우 달았다"라는 문장에서 '그것은'이라는 단어가 '사과'와 강하게 연결되는 걸 모델이 스스로 찾아내는 거예요. 마치 반 학생들이 모둠 활동을 할 때, 각자가 "이 주제에 대해서는 저 친구 말이 제일 도움 되네"라고 서로의 발언에 가중치(중요도 점수)를 매기는 것과 비슷합니다.

실습 팁: ChatGPT나 Claude 같은 AI에게 일부러 모호한 대명사가 들어간 긴 문장을 넣어보세요. 예: "철수는 영희에게 책을 주었다. 그는 그것을 도서관에서 빌렸다." 그리고 AI에게 "'그'와 '그것'이 각각 누구/무엇을 가리키는지, 왜 그렇게 판단했는지 설명해줘"라고 물어보세요. AI가 단어 간 연결(어텐션)을 어떻게 추적하는지 직접 눈으로 확인할 수 있어서, Self-Attention이 "멀리 떨어진 단어끼리도 서로 참고한다"는 원리를 체감하기 좋은 연습이 됩니다.</tip>

## 오늘의 퀴즈
Q. "나는 강가에 가서 은행에 돈을 맡겼다"라는 문장에서 '은행'이라는 단어의 의미를 컴퓨터가 정확히 이해하려면 어떻게 해야 할까요? Self-Attention의 원리를 이용해서, 컴퓨터가 이 문장에서 '은행'이 '금융기관'이라는 뜻인지 어떻게 알아낼 수 있는지 설명해보세요.
A. Self-Attention은 한 단어의 의미를 파악할 때, 문장 안에 있는 다른 모든 단어들을 같이 쳐다보면서 "이 단어들 중에 나랑 관련 깊은 단어가 뭐지?"라고 물어보는 방식이에요. 마치 교실에서 친구들이 다 같이 모여서 "얘가 무슨 뜻으로 한 말이야?"를 서로 눈치보며 파악하는 것과 비슷해요. '은행'이라는 단어는 문장 속의 '돈', '맡겼다' 같은 단어들과 강하게 연결(주목, attention)되기 때문에, '강'이라는 단어보다 '돈'과 더 관련이 깊다고 판단해서 '금융기관으로서의 은행'이라는 의미로 이해하게 되는 거예요. 즉, 단어 하나만 따로 보는 게 아니라 주변 단어들과의 관계를 계산해서 진짜 의미를 찾아내는 것이 Self-Attention의 핵심 원리입니다.
