## 오늘의 개념: SFT(지도 미세조정)란 무엇인가
SFT는 'Supervised Fine-Tuning'의 줄임말로, 우리말로는 '지도 미세조정'이라고 부릅니다. 이것을 이해하려면 먼저 AI가 어떻게 만들어지는지 요리사 훈련에 비유해볼 수 있습니다. 처음에 AI는 인터넷의 방대한 글을 읽으면서 세상의 언어와 지식을 대충 익히는데, 이는 마치 요리 학교에서 온갖 요리책을 읽고 재료와 조리법에 대한 일반 지식을 쌓는 것과 비슷합니다. 하지만 이렇게만 배운 요리사는 손님이 "배고파요, 뭐 좀 해주세요"라고 했을 때 어떻게 정중하고 도움이 되게 응답해야 하는지는 잘 모릅니다. SFT는 바로 이 단계에서, "질문: 배고파요" → "답변: 어떤 종류의 음식을 좋아하시나요? 간단한 파스타는 어떨까요?"처럼 사람이 직접 만든 좋은 질문-답변 예시들을 AI에게 여러 개 보여주면서 "이렇게 대답하는 게 좋은 거야"라고 콕 집어 가르치는 과정입니다. 즉, 이미 많은 지식을 가진 AI에게 사람이 원하는 대화 방식, 예의 바른 말투, 유용한 답변 형태를 구체적인 정답 예시로 다시 훈련시켜서 실제로 쓸모 있게 다듬는 작업이라고 이해하면 됩니다.

## 오늘의 용어: SFT (지도 미세조정, Supervised Fine-Tuning)
SFT는 이미 많은 지식을 배운 AI에게 "이런 질문엔 이렇게 대답해야 해"라는 모범 답안 예시들을 보여주며 다시 한번 훈련시키는 과정입니다. 마치 여러 나라 말을 조금씩 알고 있는 사람에게 "고객 응대할 때는 이렇게 공손하게 말해야 해"라는 정답 예시들을 반복해서 보여주며 특정 상황에 맞게 훈련시키는 것과 비슷합니다. 이 과정을 거치면 AI는 사람들이 원하는 방식으로 더 정확하고 유용하게 대답할 수 있게 됩니다.

## 예제 코드
```python
# SFT(지도 미세조정)의 원리를 아주 단순하게 흉내 낸 예제입니다.
# 실제로는 복잡한 AI 모델이 쓰이지만, 여기서는 '외우기'로 대신합니다.

# 1. 사람이 미리 만들어준 '질문-정답' 쌍 (이것을 학습 데이터라고 부릅니다)
training_data = [
    ("안녕?", "안녕하세요! 무엇을 도와드릴까요?"),
    ("너는 누구야?", "저는 도움을 드리는 AI 비서입니다."),
    ("고마워", "천만에요! 언제든지 물어보세요."),
]

# 2. AI가 배운 내용을 저장할 빈 '기억 노트' (사전이라는 자료구조 사용)
ai_memory = {}

# 3. 학습 데이터를 하나씩 보여주며 '지도(가르침)'하는 과정 = 미세조정 과정
for question, answer in training_data:
    # 질문을 외우고, 그에 맞는 정답도 함께 기억하도록 저장합니다.
    ai_memory[question] = answer
    print(f"학습 중... 질문: '{question}' -> 정답: '{answer}'")

# 4. 학습이 끝난 후, 실제로 질문을 던져서 AI가 잘 배웠는지 확인합니다.
test_question = "안녕?"
if test_question in ai_memory:
    print("\nAI의 대답:", ai_memory[test_question])
else:
    print("\nAI가 아직 배우지 못한 질문입니다.")
```
SFT(지도 미세조정, Supervised Fine-Tuning)는 이미 어느 정도 지식을 갖춘 AI에게 '질문-정답' 쌍으로 이루어진 예시들을 여러 번 보여주면서, 사람이 원하는 방식으로 대답하도록 추가로 가르치는 과정입니다. 마치 이미 글을 읽고 쓸 줄 아는 학생에게 '이런 질문에는 이렇게 답해야 한다'는 모범 답안을 계속 보여주며 시험 유형에 맞게 훈련시키는 것과 비슷합니다. 이 코드는 실제 AI 모델 없이, 그 원리를 아주 단순하게 흉내 낸 예제입니다.

## 실무 팁
SFT(지도 미세조정, Supervised Fine-Tuning)란 이미 많은 지식을 갖춘 AI에게 "이런 질문엔 이렇게 답해야 해"라는 모범 답안 예시들을 보여주며 말투와 답변 방식을 다듬는 과정입니다. 마치 요리 재료와 기본 지식은 다 아는 신입 요리사에게, 우리 식당 스타일대로 "손님이 이렇게 물으면 이렇게 대답하고 서빙하세요"라는 매뉴얼과 예시 대화를 여러 번 보여주며 훈련시키는 것과 같습니다. 실제로 적용해보려면: 자신의 업무나 서비스에서 자주 받는 질문 20~30개를 뽑아 '질문-이상적인 답변' 쌍을 표 형태(엑셀이나 JSON)로 직접 만들어보세요. 이 표가 바로 SFT에 쓰이는 '학습 데이터셋'의 축소판이며, 이렇게 직접 만들어보면 SFT가 정확히 무엇을 학습시키는 과정인지 몸으로 이해하게 됩니다.</tip>

## 오늘의 퀴즈
Q. SFT(지도 미세조정)를 쉽게 설명하면, 이미 많은 지식을 가진 AI에게 '이렇게 대답하면 좋은 대답이야'라는 예시들을 보여주면서 다시 훈련시키는 과정이라고 할 수 있어요. 마치 요리 재료와 조리법을 이미 잘 아는 사람에게, '손님에게는 이런 식으로 정중하고 친절하게 요리를 설명해서 내놓아야 해'라는 모범 답안들을 보여주며 서빙 매너를 가르치는 것과 비슷해요. 그렇다면 SFT를 하기 전의 AI와 SFT를 하고 난 후의 AI는 무엇이 가장 크게 달라질까요? (AI가 알고 있는 지식의 양이 달라지는 것이 아니라는 점에 유의해서 답해보세요)
A. SFT를 해도 AI가 알고 있는 지식의 양 자체는 크게 늘어나지 않아요. 왜냐하면 지식은 이미 그 전 단계(사전학습)에서 인터넷의 방대한 글을 읽으며 다 배워놨기 때문이에요. SFT를 통해 달라지는 것은 '지식을 표현하는 방식과 태도'예요. 예를 들어 질문에 동문서답하거나 두서없이 답하던 AI가, SFT를 거치면 질문의 의도를 파악해서 친절하고 명확하게, 사람들이 원하는 형식으로 대답하는 법을 배우게 돼요. 즉 '아는 것'이 아니라 '아는 것을 어떻게 잘 전달하는지'가 좋아지는 거예요.
