## 오늘의 개념: 코사인 유사도란 무엇인가
코사인 유사도는 두 개의 문장이나 단어, 데이터가 서로 얼마나 비슷한 의미나 방향을 가지고 있는지를 숫자로 나타내는 방법이다. 컴퓨터는 글자를 그대로 이해하지 못하기 때문에 단어나 문장을 여러 개의 숫자로 이루어진 화살표(방향과 크기를 가진 값) 형태로 바꾸는데, 이를 '벡터'라고 부른다. 코사인 유사도는 두 화살표가 얼마나 같은 방향을 가리키고 있는지를 비교해서, 방향이 완전히 같으면 1, 완전히 반대면 -1, 서로 관련이 없으면 0에 가까운 값을 준다. 비유하자면, 두 사람이 나침반을 들고 있을 때 두 사람이 가리키는 방향이 비슷할수록 '생각이 비슷하다'고 보는 것과 같다. 예를 들어 '강아지가 귀엽다'와 '강아지가 사랑스럽다'라는 두 문장은 코사인 유사도로 계산했을 때 방향이 비슷해서 높은 값이 나오고, 이런 원리로 AI는 문서 검색이나 추천 시스템에서 비슷한 내용을 찾아준다.

## 오늘의 용어: 코사인 유사도 (Cosine Similarity)
코사인 유사도는 두 개의 정보(예를 들어 문장이나 단어)가 서로 얼마나 비슷한 의미나 방향을 가지고 있는지를 숫자로 재는 방법이다. 예를 들어 나침반 바늘 두 개가 있을 때, 두 바늘이 가리키는 방향이 완전히 같으면 '아주 비슷하다', 서로 반대 방향을 가리키면 '전혀 다르다'라고 판단하는 것과 비슷하다. AI는 문장이나 단어를 화살표(방향과 크기를 가진 값)로 바꾼 뒤, 두 화살표가 얼마나 같은 방향을 향하는지를 계산해서 두 문장이 비슷한 의미인지 아닌지를 판단하는 데 이 방법을 사용한다.

## 예제 코드
```python
import math  # 제곱근 같은 수학 계산을 도와주는 도구를 가져옵니다

# 문장을 숫자 목록(벡터)으로 표현했다고 가정합니다
# 예: [사과 단어 개수, 바나나 단어 개수] 처럼 각 숫자가 어떤 특징의 정도를 나타냅니다
vector_a = [2, 0]  # 예: "사과 사과" 라는 문장
vector_b = [4, 0]  # 예: "사과 사과 사과 사과" 라는 문장 (사과 방향은 같음)

# 두 벡터의 내적(각 자리 숫자를 곱한 뒤 다 더하는 것)을 구합니다
dot_product = sum(a * b for a, b in zip(vector_a, vector_b))

# 벡터의 길이(크기)를 구합니다. 피타고라스 정리처럼 제곱해서 더한 뒤 제곱근을 씌웁니다
length_a = math.sqrt(sum(a * a for a in vector_a))
length_b = math.sqrt(sum(b * b for b in vector_b))

# 코사인 유사도 = 내적 값을 두 벡터 길이의 곱으로 나눈 것
# 값이 1에 가까울수록 두 문장의 방향(내용의 경향)이 비슷하다는 뜻입니다
cosine_similarity = dot_product / (length_a * length_b)

# 결과를 출력합니다 (1.0이 나오면 완전히 같은 방향이라는 의미입니다)
print("코사인 유사도:", cosine_similarity)

```
코사인 유사도는 두 가지가 얼마나 '비슷한 방향'을 가지고 있는지를 재는 방법입니다. 예를 들어 두 사람이 걸어가는 방향이 완전히 같으면 '아주 비슷하다', 정반대 방향이면 '전혀 다르다', 직각으로 갈라지면 '중간 정도 다르다'고 말할 수 있는 것과 비슷합니다. 이 코드에서는 문장을 숫자 목록(벡터)으로 표현한 뒤, 두 문장이 얼마나 비슷한 방향을 가리키는지를 계산해봅니다.

## 실무 팁
코사인 유사도는 두 문장(또는 단어)이 '같은 방향을 보고 있는지'를 재는 방법이에요. 예를 들어 나침반 바늘 두 개가 있을 때, 두 바늘이 똑같은 방향을 가리키면 관련성이 높고(1에 가까움), 정반대를 가리키면 관련성이 없는(0이나 음수) 거라고 생각하면 됩니다. 실제로 적용해보려면, 파이썬에서 문장을 벡터(숫자 목록)로 바꿔주는 사이킷런(scikit-learn) 라이브러리의 TfidfVectorizer로 두 문장을 벡터화한 뒤, cosine_similarity 함수에 넣어보세요. 코드 예시: from sklearn.feature_extraction.text import TfidfVectorizer; from sklearn.metrics.pairwise import cosine_similarity; vec = TfidfVectorizer(); tfidf = vec.fit_transform(["나는 사과를 좋아해", "나는 바나나를 좋아해"]); print(cosine_similarity(tfidf[0], tfidf[1])). 이렇게 직접 두 문장을 바꿔가며 결과 숫자가 어떻게 변하는지 확인해보면 '유사도'라는 개념이 몸으로 이해됩니다.

## 오늘의 퀴즈
Q. 두 편의 글이 있는데, 하나는 "나는 강아지를 좋아한다"이고 다른 하나는 "나는 강아지를 정말 정말 정말 좋아한다"야. 단어 개수는 다르지만 두 글이 말하고자 하는 '방향'(의미, 감정)은 비슷하다고 느껴져. 코사인 유사도로 이 두 글을 비교하면 유사도 값이 높게 나올까, 낮게 나올까? 그 이유는 무엇일까?
A. 코사인 유사도는 두 화살표(벡터)가 얼마나 '같은 방향'을 가리키는지를 보는 방법이야. 화살표의 길이(글자 수나 단어 반복 횟수 같은 크기)는 신경 쓰지 않고, 오직 방향이 얼마나 비슷한지만 봐. 위 두 글은 "강아지를 좋아한다"는 같은 방향을 가리키고 있고, 단지 강조하는 정도(길이)만 다르기 때문에 코사인 유사도는 높게 나와. 비유하자면, 두 사람이 같은 목적지를 향해 걷고 있는데 한 명은 천천히, 한 명은 빨리 걷는 것뿐이야. 걷는 속도(크기)는 다르지만 향하는 방향은 같으니까 '방향이 비슷하다'고 보는 코사인 유사도는 두 사람을 매우 비슷하다고 판단하는 거지.
