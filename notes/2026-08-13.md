## 오늘의 개념: LoRA란 무엇인가
LoRA는 이미 잘 만들어진 거대한 AI 모델을 처음부터 다시 훈련시키지 않고, 아주 적은 비용으로 특정 목적에 맞게 살짝 바꾸는 기술입니다. 비유하자면, 이미 완성된 두꺼운 백과사전(거대 AI 모델)이 있는데, 이 책 전체를 다시 쓰는 대신 필요한 부분에만 '포스트잇 메모'를 붙여서 원하는 정보를 추가하는 것과 비슷합니다. 이 포스트잇에 해당하는 부분이 아주 작고 가벼운 데이터라서, 저장 공간도 적게 차지하고 학습 속도도 훨씬 빠릅니다. 예를 들어 어떤 그림 그리는 AI가 있는데, 이 AI가 특정 화가의 화풍을 따라 그리게 만들고 싶을 때, 전체 AI를 새로 훈련시키는 대신 LoRA라는 작은 조각만 추가로 학습시켜서 붙이면 원하는 화풍을 흉내낼 수 있습니다. 그래서 LoRA는 적은 컴퓨터 자원으로도 AI를 내 입맛에 맞게 customizing(맞춤 설정)할 수 있게 해주는 효율적인 방법으로 널리 쓰입니다.

## 오늘의 용어: LoRA (로라, Low-Rank Adaptation)
LoRA는 이미 다 만들어진 거대한 AI 모델을 처음부터 다시 학습시키지 않고, 아주 작은 부분만 추가로 학습시켜서 새로운 능력을 붙이는 기술이에요. 비유하자면, 이미 완성된 두꺼운 책 전체를 다시 쓰는 대신 얇은 '포스트잇 메모지'를 몇 장 붙여서 필요한 내용만 살짝 수정하는 것과 비슷합니다. 이렇게 하면 시간과 컴퓨터 자원을 훨씬 적게 쓰면서도, AI가 특정 그림 스타일을 따라 그리거나 특정 말투로 대답하는 등 원하는 방향으로 맞춤 조정을 할 수 있어요.

## 예제 코드
```python
import numpy as np  # 숫자들을 표(행렬) 형태로 다루기 위한 도구를 가져옵니다

# 원래의 '큰 인공지능 모델'이라고 생각할 숫자표입니다 (실제로는 훨씬 크지만 예시로 작게 만듭니다)
W_original = np.array([[1.0, 2.0],
                        [3.0, 4.0]])  # 이 값은 학습 중에 절대 바꾸지 않습니다 (고정)

# LoRA에서 새로 추가하는 '작은 포스트잇' 역할을 하는 두 개의 작은 표입니다
A = np.array([[0.1, 0.2]])   # 첫 번째 작은 표 (예: 1x2 크기)
B = np.array([[0.3],
              [0.4]])        # 두 번째 작은 표 (예: 2x1 크기)

# A와 B를 곱해서 아주 작은 '수정용 표'를 만듭니다 (이 부분만 학습하면 됩니다)
delta_W = B @ A  # @ 는 행렬끼리 곱하는 기호입니다

# 원래 표에 작은 수정값을 더해서 최종적으로 사용할 표를 만듭니다
W_updated = W_original + delta_W

# 결과를 출력해서 원래 표가 어떻게 살짝 바뀌었는지 확인합니다
print("원래 큰 표(변하지 않음):\n", W_original)
print("작은 수정값(LoRA로 학습하는 부분):\n", delta_W)
print("최종적으로 사용하는 표(원래 + 수정값):\n", W_updated)

```
LoRA(로라)는 큰 인공지능 모델을 아주 조금만 바꿔서 새로운 능력을 추가하는 기술입니다. 비유를 들면, 두꺼운 백과사전(원래 모델) 전체를 다시 쓰는 대신, 얇은 '포스트잇 메모지(작은 추가 부분)'를 붙여서 필요한 부분만 살짝 고치는 것과 같습니다. 이 코드는 원래의 큰 숫자표(가중치)는 그대로 두고, 아주 작은 두 개의 숫자표(A, B)만 곱해서 만든 '작은 수정값'을 원래 표에 더해주는 과정을 보여줍니다. 즉, 무겁고 큰 것을 통째로 바꾸지 않고, 작고 가벼운 것만 학습해서 붙이는 아이디어를 흉내낸 예제입니다.

## 실무 팁

Q. 거대한 AI 모델 전체를 처음부터 다시 학습시키는 것과, LoRA를 사용해서 학습시키는 것은 무엇이 다를까요? 비유를 들어 설명해보세요.
A. 전체 재학습은 두꺼운 백과사전 전체를 처음부터 다시 쓰는 것과 비슷해서 시간과 비용이 엄청나게 많이 듭니다. 반면 LoRA는 원래 백과사전은 그대로 두고, 필요한 부분에 '수정 메모지(스티커)'만 살짝 붙여서 원하는 방향으로 살짝 바꾸는 방법입니다. 즉 원본 모델(거대한 지식)은 건드리지 않고, 적은 양의 추가 정보(작은 조각들)만 학습시켜서 적은 비용과 시간으로도 모델을 특정 목적에 맞게 바꿀 수 있다는 것이 핵심 개념입니다.</answer>
