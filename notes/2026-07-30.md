## 오늘의 개념: Temperature 값은 답변에 어떤 영향을 주는가
AI가 문장을 만들 때는 다음에 나올 단어를 하나 고르는 과정을 계속 반복하는데, 이때 각 단어마다 '이 단어가 나올 확률이 몇 퍼센트다'라는 점수를 매깁니다. temperature는 이 확률 점수를 얼마나 과감하게 섞을지 정하는 손잡이 같은 값이라고 생각하면 됩니다. temperature를 낮게 설정하면(예: 0에 가깝게) AI는 가장 확률 높은 단어만 고르려고 해서 답변이 안정적이고 예측 가능하지만 조금 뻔하고 딱딱해질 수 있습니다. 반대로 temperature를 높게 설정하면 확률이 낮은 단어도 선택될 기회가 늘어나서 답변이 더 창의적이고 다양해지지만, 가끔은 엉뚱하거나 말이 안 되는 문장이 나올 수도 있습니다. 비유하자면, 요리할 때 항상 똑같은 레시피대로만 만드는 요리사(낮은 temperature)와 가끔 새로운 재료를 과감하게 넣어보는 요리사(높은 temperature)의 차이와 비슷합니다.

## 오늘의 용어: Temperature (온도) 값
AI가 문장을 만들 때 다음에 올 단어를 얼마나 '모험적으로' 고를지 정하는 설정값이에요. 예를 들어 요리사에게 '늘 하던 대로 안전하게 만들어줘'라고 하면 값이 낮은 것이고, '오늘은 새로운 재료도 넣어서 창의적으로 만들어봐'라고 하면 값이 높은 거예요. 값이 낮으면 AI는 예측 가능하고 일관된 답변을 주고, 값이 높으면 더 다양하고 창의적이지만 가끔 엉뚱한 답변을 줄 수 있습니다.</definition>

## 예제 코드
```python
import random

# 사용할 수 있는 단어 후보들 (실제 AI라면 훨씬 더 많은 단어를 고려합니다)
words = ["강아지는 귀엽다", "강아지는 사랑스럽다", "강아지는 시끄럽다", "강아지는 신비롭다"]

# temperature가 낮을수록 항상 첫 번째(가장 무난한) 답을 고르도록 흉내낸 함수
def fake_ai_answer(temperature):
    # temperature가 0에 가까우면 무조건 가장 안전한 답(0번째)을 선택
    if temperature < 0.3:
        return words[0]
    # temperature가 높으면 무작위로 답을 선택해서 다양성을 흉내냄
    else:
        return random.choice(words)

# temperature 0.1 (낮음): 안정적이고 뻔한 답이 나옵니다
print("temperature=0.1 ->", fake_ai_answer(0.1))
print("temperature=0.1 ->", fake_ai_answer(0.1))  # 계속 같은 답

# temperature 0.9 (높음): 매번 다른, 더 다양한 답이 나올 수 있습니다
print("temperature=0.9 ->", fake_ai_answer(0.9))
print("temperature=0.9 ->", fake_ai_answer(0.9))  # 답이 바뀔 수 있음

```
AI에게 질문을 하면 답을 만들어내는데, 이때 "temperature"라는 값이 답의 성격을 조절합니다. temperature는 쉽게 말하면 "AI가 얼마나 모험을 하는지"를 정하는 다이얼 같은 것입니다. 값이 낮으면(예: 0) AI는 항상 가장 안전하고 뻔한 답을 골라서 매번 거의 똑같은 대답을 하고, 값이 높으면(예: 1) AI는 조금 더 엉뚱하고 다양한 단어를 골라서 매번 다른 대답을 합니다. 마치 요리할 때 정해진 레시피만 따르는 요리사(낮은 temperature)와, 즉흥적으로 재료를 바꿔가며 창의적인 요리를 시도하는 요리사(높은 temperature)의 차이와 비슷합니다. 아래 코드는 실제 AI를 호출하지 않고, temperature 개념을 아주 단순화한 가짜(mock) 예제로 보여줍니다.

## 실무 팁
'temperature'는 AI가 답변을 만들 때 얼마나 '모험을 하는지'를 정하는 다이얼입니다. 요리에 비유하면, temperature가 낮을수록(예: 0~0.3) 늘 먹던 익숙하고 안전한 레시피대로 만드는 것이고, 높을수록(예: 0.8~1.2) 새로운 재료를 섞어보며 창의적이지만 가끔 이상한 요리가 나올 수도 있는 것과 같습니다. 실제로 써보는 방법: ChatGPT 같은 서비스의 API나 설정에서 temperature 값을 조절할 수 있다면, 코드 작성·사실 정리·요약처럼 '정확함'이 중요한 작업은 0~0.3으로 낮게 설정하고, 아이디어 브레인스토밍·소설 쓰기·카피라이팅처럼 '다양함'이 중요한 작업은 0.7~1.0으로 높게 설정해보세요. 같은 질문을 temperature 0.2와 0.9로 각각 물어보고 답변을 비교해보면 차이를 바로 체감할 수 있습니다.</tip>

## 오늘의 퀴즈
Q. AI 챗봇에게 똑같은 질문을 여러 번 했을 때, temperature 값을 낮게(예: 0) 설정했을 때와 높게(예: 1.5) 설정했을 때 나오는 답변들이 어떻게 다를지 비유를 들어 설명해보세요.
A. temperature는 AI가 답을 고를 때 얼마나 '모험'을 하는지 정하는 다이얼 같은 거예요. 요리에 비유하면, temperature가 낮을 때는 항상 정해진 레시피대로만 요리하는 셰프처럼, AI가 매번 가장 확률 높고 무난한 단어만 골라서 거의 똑같고 안정적인 답변을 내놔요. 반대로 temperature가 높으면, 새로운 재료를 이것저것 실험해보는 셰프처럼 AI가 확률이 낮은 단어도 과감히 골라서 매번 다르고 창의적이지만 가끔은 엉뚱하거나 이상한 답변이 나올 수 있어요.
