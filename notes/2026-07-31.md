## 오늘의 개념: Ollama로 로컬 컴퓨터에서 LLM 실행하기
LLM(거대 언어 모델)이란 사람처럼 글을 이해하고 대답을 만들어내는 AI 프로그램을 말합니다. 우리가 흔히 쓰는 ChatGPT 같은 서비스는 이 AI가 회사의 인터넷 서버(멀리 있는 대형 컴퓨터)에서 돌아가고, 우리는 인터넷을 통해 질문을 보내고 답을 받는 방식입니다. 반면 Ollama는 이런 거대한 AI 모델을 인터넷 없이 내 컴퓨터 안에서 직접 실행할 수 있게 도와주는 프로그램입니다. 비유하자면, 매번 식당에 전화 주문해서 배달받아 먹는 대신, 요리 재료와 레시피를 통째로 집에 들여놓고 내 주방에서 직접 요리해 먹는 것과 비슷합니다. 이렇게 하면 인터넷 연결이 끊겨도 사용할 수 있고, 내 질문 내용이 외부 서버로 전송되지 않아 개인정보를 더 안전하게 지킬 수 있다는 장점이 있습니다.

## 오늘의 용어: Ollama (올라마)
Ollama는 인터넷 없이도 내 개인 컴퓨터 안에서 ChatGPT 같은 AI 언어 모델(LLM)을 직접 설치하고 실행할 수 있게 도와주는 프로그램이에요. 마치 넷플릭스처럼 인터넷 스트리밍으로 영화를 보는 대신, 영화 파일을 내 컴퓨터에 다운로드해서 오프라인으로 보는 것과 비슷한 방식이라고 생각하면 됩니다. 덕분에 내 데이터를 외부 서버로 보내지 않고도, 그리고 별도의 이용 요금 없이 AI를 사용할 수 있어요.

## 예제 코드
```python
# ollama 패키지를 사용하기 위해 불러옵니다 (미리 pip install ollama 로 설치해야 함)
import ollama

# AI에게 물어볼 질문을 문자열(글자들의 모음)로 만듭니다
my_question = "파이썬이 뭔지 아주 쉽게 한 문장으로 설명해줘"

# ollama.chat 함수를 이용해 내 컴퓨터에 설치된 AI 모델에게 질문을 보냅니다
# model 값에는 미리 받아둔 모델 이름(예: "llama3")을 적어줍니다
response = ollama.chat(
    model="llama3",
    messages=[
        {"role": "user", "content": my_question}
    ]
)

# AI가 돌려준 답변 중에서 실제 텍스트 내용만 꺼냅니다
answer_text = response["message"]["content"]

# 화면에 AI의 답변을 출력합니다
print("AI의 답변:", answer_text)

```
이 코드는 'Ollama'라는 프로그램을 이용해서 내 컴퓨터 안에서 직접 AI(거대 언어 모델, LLM)와 대화하는 아주 짧은 예제예요. 인터넷에 있는 유료 AI 서비스(예: ChatGPT 웹사이트)에 접속하지 않고도, 마치 내 컴퓨터 안에 작은 AI 비서를 설치해두고 질문하는 것과 비슷하다고 생각하면 됩니다. 코드를 실행하기 전에 컴퓨터에 Ollama 프로그램을 먼저 설치하고, 터미널에서 'ollama pull llama3' 같은 명령어로 AI 모델(두뇌 역할을 하는 데이터 파일)을 미리 받아둬야 해요.

## 실무 팁
Ollama는 큰 AI 언어모델(LLM, 사람처럼 글을 이해하고 대답하는 프로그램이라고 생각하면 됩니다)을 인터넷 없이 내 컴퓨터에서 직접 돌릴 수 있게 해주는 도구입니다. 마치 넷플릭스로 영화를 스트리밍하는 대신, 영화 파일을 통째로 다운받아서 내 컴퓨터에서 재생하는 것과 비슷합니다.

실전 팁: 처음 설치했다면 터미널(컴퓨터에 명령어를 직접 입력하는 검은 화면)에서 아래처럼 실행해보세요.

1. `ollama run llama3.2` 입력 → 처음엔 자동으로 모델 파일을 다운받고(약 2GB), 다운로드가 끝나면 바로 채팅창처럼 대화할 수 있습니다.
2. 만약 컴퓨터가 느리거나 램(RAM, 컴퓨터가 작업을 처리하기 위해 잠깐 쓰는 메모리 공간)이 8GB 이하라면, `llama3.2` 대신 더 가벼운 버전인 `ollama run llama3.2:1b`를 입력하세요. 모델 크기가 작을수록 실행 속도는 빠르지만 대답 품질은 조금 떨어집니다.
3. 대화가 끝나면 `/bye`라고 입력하면 종료됩니다.

이렇게 하면 회원가입이나 API 키 발급 없이 바로 내 컴퓨터에서 AI와 대화를 시작할 수 있습니다.

## 오늘의 퀴즈
Q. Ollama를 사용해서 내 컴퓨터에서 LLM(거대 언어 모델)을 직접 실행한다는 것은, 마치 인터넷에서 요리 배달 앱으로 음식을 주문하는 대신 내 집 주방에서 직접 요리를 만들어 먹는 것과 비슷해요. 그렇다면 ChatGPT 같은 서비스를 인터넷으로 사용하는 것과 비교했을 때, Ollama로 로컬(내 컴퓨터)에서 LLM을 실행하면 어떤 점이 다르고 어떤 장점이 있을까요?
A. ChatGPT처럼 인터넷으로 AI를 사용하면, 내가 입력한 질문이나 정보가 인터넷을 통해 다른 회사의 컴퓨터(서버)로 전송되어 그곳에서 처리된 후 답이 돌아옵니다. 배달 음식을 시키면 재료와 조리 과정을 내가 볼 수 없고, 음식점 주방(남의 컴퓨터)에서 만들어지는 것과 같아요.

반면 Ollama로 로컬에서 LLM을 실행하면, AI 모델 자체를 내 컴퓨터에 다운로드해서 설치하고, 질문을 입력하면 내 컴퓨터의 CPU나 GPU가 직접 계산해서 답을 만들어냅니다. 마치 내 집 주방에서 직접 요리하는 것처럼, 재료(데이터)가 집 밖으로 나가지 않아요.

그래서 장점은 첫째, 인터넷 연결이 없어도 사용할 수 있고 둘째, 내가 입력한 개인 정보나 민감한 내용이 외부 서버로 전송되지 않아 보안과 개인정보 보호에 유리하며 셋째, 사용량에 따른 요금을 내지 않아도 된다는 점입니다. 다만 내 컴퓨터의 성능(특히 그래픽카드 성능과 메모리 용량)이 충분해야 AI가 원활하게 작동한다는 제약이 있습니다.
