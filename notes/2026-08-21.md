## 오늘의 개념: LLM 성능은 어떻게 평가하는가
LLM(엘엘엠)이란 '거대 언어 모델'이라는 뜻으로, 사람처럼 글을 읽고 쓸 수 있게 만든 AI 프로그램을 말합니다. 이런 AI가 얼마나 똑똑하고 정확하게 대답하는지를 확인하려면, 마치 학생의 실력을 알아보기 위해 시험을 보는 것처럼 AI에게도 다양한 '문제집(벤치마크라고 부릅니다)'을 풀게 합니다. 예를 들어 수학 문제, 상식 퀴즈, 코딩 문제 등을 미리 정답이 있는 문제로 만들어 놓고 AI가 낸 답과 정답을 비교해서 몇 점을 맞았는지 점수를 매기는 방식입니다. 어떤 경우에는 정답이 딱 하나로 정해지지 않는 글쓰기 같은 문제도 있는데, 이때는 사람이 직접 AI의 답변을 읽고 '이 답변이 얼마나 자연스럽고 도움이 되는지'를 채점하거나, 심지어 또 다른 AI에게 채점을 맡기기도 합니다. 결국 LLM 성능 평가란, 다양한 시험 문제를 통해 AI의 언어 이해력, 문제 해결 능력, 답변의 품질을 숫자나 등급으로 확인하는 과정이라고 이해하면 됩니다.

## 오늘의 용어: 벤치마크 (Benchmark)
AI(인공지능) 모델이 얼마나 똑똑하고 정확하게 답하는지 확인하기 위해 만들어 놓은 '시험 문제 세트'를 말합니다. 마치 학생들의 실력을 비교하려고 전국 모의고사를 치르는 것처럼, 여러 AI 모델에게 똑같은 문제들을 풀게 해서 누가 더 잘하는지 점수로 비교하는 것입니다. 예를 들어 수학 문제, 상식 퀴즈, 코딩 문제 등을 모아놓은 벤치마크가 있으면, 이를 통해 'A 모델이 B 모델보다 수학을 더 잘한다'는 식으로 성능을 객관적으로 평가할 수 있습니다.

## 예제 코드
```python
# 정답(사람이 미리 준비한 진짜 답)들을 리스트(목록)로 만듭니다
answers = ["파리", "지구", "물"]

# AI(LLM)가 실제로 내놓은 답들을 리스트로 만듭니다
ai_outputs = ["파리", "달", "물"]

# 맞은 개수를 세기 위한 변수(숫자를 담는 상자)를 0으로 시작합니다
correct_count = 0

# 정답과 AI 답을 하나씩 짝지어 비교합니다 (반복문 사용)
for answer, ai_output in zip(answers, ai_outputs):
    # 정답과 AI의 답이 똑같은지 확인합니다
    if answer == ai_output:
        # 같다면 맞은 개수를 1 늘립니다
        correct_count += 1

# 전체 문제 개수를 구합니다
total_count = len(answers)

# 정확도(맞은 비율)를 계산합니다: 맞은 개수 나누기 전체 개수
accuracy = correct_count / total_count

# 결과를 화면에 출력합니다 (예: 0.67 == 67% 정도 맞췄다는 뜻)
print("AI의 정답률:", accuracy)

```
이 코드는 'LLM(거대언어모델) 성능 평가'가 무엇인지 아주 쉬운 예시로 보여줍니다. LLM은 사람처럼 글을 쓰거나 질문에 답하는 인공지능 프로그램인데, 시험을 보고 채점을 하듯이 'AI가 낸 답'과 '정답'을 비교해서 몇 개나 맞았는지 점수를 매기는 방식으로 성능을 평가할 수 있습니다. 마치 선생님이 학생의 시험지를 정답지와 대조해서 몇 점인지 계산하는 것과 같은 원리입니다.

## 실무 팁

## 오늘의 퀴즈
Q. LLM(거대 언어모델, 사람처럼 글을 이해하고 만들어내는 AI 프로그램)의 성능을 평가할 때, 왜 단순히 '정답을 몇 개 맞췄는가'만 보는 것으로는 부족할까요? 시험을 예로 들어 설명해보세요.
A. 학생이 시험에서 100점을 받았다고 해서 실제로 그 과목을 완전히 이해했다고 단정할 수 없는 것처럼, LLM도 특정 문제 유형에서 점수가 높다고 해서 모든 상황에서 잘한다고 볼 수 없기 때문입니다. 예를 들어 객관식 문제(정답이 딱 정해진 문제)는 잘 맞춰도, 창의적인 글쓰기나 대화처럼 정답이 하나로 정해지지 않은 상황에서는 엉뚱하거나 사실과 다른 답을 할 수 있습니다. 그래서 LLM을 평가할 때는 정확도(맞은 개수) 외에도 '얼마나 자연스러운 문장을 만드는지', '사실과 다른 거짓말(할루시네이션)을 하지 않는지', '위험하거나 편향된 답을 하지 않는지' 등 여러 기준을 함께 살펴봐야 합니다. 마치 학생을 평가할 때 시험 점수뿐 아니라 발표력, 협동심, 창의력도 함께 보는 것과 비슷합니다.
